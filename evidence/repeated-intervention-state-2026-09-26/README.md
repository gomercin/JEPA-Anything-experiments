This incremental package uses the existing portable file index and exclusive
archive-restoration helpers. `artifacts.json` records every original member's

into the uniquely named Git-resident archive; no old tag, archive, checkpoint or
release asset is replaced. Compression keeps generated Git evidence below25MiB
without rewriting any sealed bytes. Figures are additionally visible directly.
