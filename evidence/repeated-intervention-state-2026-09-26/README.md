# Two actual interventions: portable evidence

The [living findings](../../experiments/mediated_patterns/REPEATED_INTERVENTION_STATE.md)
separate unchanged nine-state reuse, a failed scalar readout repair, and a selected
composition-informed eleven-state construction. All substantive stages, including
failures, are retained. [Critical review](review.md) covers physical events,
information boundaries, numerical qualifications, exposure and claims.

This incremental package uses the existing portable file index and exclusive
archive-restoration helpers. `artifacts.json` records every original member's
size and SHA256 plus the local archive checksum. Only this study is compressed
into the uniquely named Git-resident archive; no old tag, archive, checkpoint or
release asset is replaced. Compression keeps generated Git evidence below25MiB
without rewriting any sealed bytes. Figures are additionally visible directly.
No network or scientific simulation runs during restoration.

```bash
python evidence/repeated-intervention-state-2026-09-26/restore.py --verify-only
python evidence/repeated-intervention-state-2026-09-26/restore.py --destination /tmp/repeated-evidence-new
python -m pytest evidence/repeated-intervention-state-2026-09-26/tests -q
```

The restored tree is `work/mediated_patterns/repeated_intervention_state/`.
`commands.txt` records exact invocations. Every stage records its source commit,
source hashes and charged CPU time. Use the recorded revision for historical
stages; later source includes both diagnostic repair families. `frozen-01/`
contains the original and selected models and the prospective fresh contract.
`fresh-01/seal.json` identifies every prediction/checkpoint saved before any
post-initialization nonlinear reference. Runtime audit has only inference code,
coefficients, retained states and schedules: scientific imports and field array
reads are denied. Tests replay score and eight-branch arithmetic without rerunning
the field panel. Prior one-event, unforced, snapshot and spatial-hybrid archives
remain authoritative and unchanged.
