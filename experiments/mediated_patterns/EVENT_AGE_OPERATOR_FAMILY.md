# Event age as known context for a shared response operator

**FIXED-AGE MAPS WORK BUT SHARED FAMILY FAILS.** All five fixed-age maps pass
preparation-grouped development gates in a common rank4 temporal representation.
Pooling without age fails the event contrast. Explicit quadratic age context
improves it, and the one fixed-knot natural spline improves it further, but the
spline still misses38 resolved full-age-holdout gates. All large conditional R
gates pass. The failure precedes fresh access: age24, seeds26101–26103, retained
G deployment and repeated diagnostics were **not run**.

At identical supported centers, the operators change smoothly but with substantial
curvature. The odd-amplitude contribution dominates; some mass/early-moment
curves change sign as age changes. The largest adjacent change is10→15:
RMS D1 differences across common supported centers are about1.12e-10 mass and
3.91e-11 moment, versus2.00e-11 and6.84e-12 for20→30. The latter interval is twice

`operators-01/operators.npz` and `diagnosis-02/common-basis-trajectories.npz`
retain coefficient matrices and common-basis response weights. SVD directions
and regression coefficients are not assigned physical meaning.

The age-blind failure shows that the tested pooled quadratic cannot ignore
context; it does not prove that no center-only function could encode timing.
Explicit age adds substantial predictive value but does not yet earn the complete
shared-family sufficiency claim. A spline with all ages present can fit the
surface, while its interpolation without an interior age remains inaccurate.
No distinct physical descriptor or hidden memory necessity follows. Nor does this
limited failure establish qualitatively different effective descriptions: better
ordinary approximation remains an open possibility, not an experiment launched
here.

## Explicit stop and information costs

No model was frozen for fresh access. Prospective age24 and seeds26101–26103
remain unused. There is no fresh R/D1 result, per-age post-hoc oracle, new G
propagation accuracy, or new R11/D12/D2|1/K12 result. Conditional runner paths and
synthetic access-order tests exist, but unused code is not scientific evidence.
No autonomous response memory was added and no composition fitting occurred.

Each snapshot query acquires three current weighted centers from a field scan,
and receives conditioning amplitude plus known age context. There are no later
fields, true baselines, rates, seed/write labels or response lookups in inference.
The pooled control ignores age in its features. Baseline and conditioned R are
computed independently; D1 is formed afterward. These are response operators,
not retained post-event states or absolute-Y simulators.

quadratic context stores2018; spline stores2258. The two bases account for1288
values, center scaling6, output scaling4, and coefficient matrices240/720/960.
